# Code Review Platform

Real-time collaborative code review platform with AI-powered analysis and microservices architecture.

## 🎯 Description

A learning project building a production-grade distributed system for code review, combining AI analysis with real-time collaboration.

## 🛠️ Tech Stack

- Spring Boot 4.0.2
- PostgreSQL 15
- Docker
- JWT Authentication
- Maven

## 📦 Setup

### Start Database
```bash
docker-compose up -d
```

### Run Application
```bash
./mvnw spring-boot:run
```
